## Sobre mim

Meu ponto de partida no desenvolvimento backend é a experiência com dados, sistemas de negócio e atendimento a usuários — hoje eu aplico essa mesma lógica escrevendo código. Sou estudante de Análise e Desenvolvimento de Sistemas na UNINOVE (conclusão prevista pra dezembro de 2027) e trabalho hoje como Assistente Administrativo no Grupo Innova Steel, onde uso SQL todos os dias no Oracle/Orion pra apoiar franqueados e investigar inconsistências operacionais.

Nos projetos de estudo eu construo em Go: no **helpdesk-api-go**, implementei um endpoint de criação de chamados com `net/http`, validação de campos obrigatórios, respostas em JSON e persistência com `pgx` em PostgreSQL, com o ambiente todo configurado em Docker Compose. No **go-site-monitor**, uma CLI que consulta endereços por HTTP e registra o resultado das verificações em arquivo.

Estou buscando minha primeira vaga como Desenvolvedor(a) Backend Júnior ou estagiário, com foco em Go — remoto (qualquer lugar do Brasil) ou presencial/híbrido na zona leste de São Paulo.
