Minha trajetória profissional começou próxima de **sistemas, usuários e problemas operacionais reais**. Atualmente, atuo como Assistente Administrativo no Grupo Innova Steel, com atividades que envolvem suporte a franqueados, elaboração e acompanhamento de orçamentos, planilhas e forecast, consultas SQL no sistema Orion, ERP Construshow, dashboards, relatórios, análise de inconsistências e suporte a usuários.

Essa experiência me ensinou a investigar problemas, compreender fluxos, comunicar soluções e perceber como uma decisão de sistema afeta diretamente o trabalho das pessoas.

Hoje, transformo essa base em prática de desenvolvimento, tendo **Go como tecnologia principal** e utilizando Angular, TypeScript, APIs REST, SQL, Git e GitHub para construir uma formação técnica consistente.

Busco minha primeira oportunidade profissional como desenvolvedor de software júnior, com disposição para aprender, receber revisão de código e evoluir ao lado de profissionais mais experientes.

- Comecei em ambientes operacionais, onde organização, prazo e comunicação eram essenciais.

- Escolhi o desenvolvimento para ir além do uso dos sistemas e aprender a construir soluções.

<details>
  <summary><strong>Como procuro trabalhar</strong></summary>
  <br>

1. Entender o problema e quem será afetado por ele.
2. Definir o fluxo principal antes de adicionar complexidade.
3. Dividir a implementação em pequenas entregas verificáveis.
4. Tratar erros e situações inválidas de forma clara.
5. Pedir revisão, corrigir e documentar o que foi construído.

</details>
